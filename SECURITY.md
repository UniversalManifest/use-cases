# Security Policy

This repository holds use-case write-ups, not software. For a vulnerability in the Universal Manifest specification or its reference implementations, see the [specification repository's security policy](https://github.com/UniversalManifest/universal-manifest/blob/main/SECURITY.md).

## Reporting

**Do not open public GitHub issues for security vulnerabilities.**

Report security issues by email to **security@universalmanifest.net**. Include a description, the affected document or version, and the potential impact.

## Response

Reports are read and assessed by the maintainers. No fixed response time is promised.
